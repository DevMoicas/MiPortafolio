Proyecto Login con XAMPP

¿Qué es este login?

Este login es un proyecto el cual fue creado en marzo del 2025, dicho proyecto representa lo que es un inicio de sesión funcional y también el uso del API de google recaptcha para cuestiones de seguridad.

Objetivo de crear el login

El objetivo de crear este login fue profundizar mis conocimientos en desarrollo web, centrándome especialmente en la parte lógica. Utilicé XAMPP como servidor local, lo que me permitió gestionar y controlar los usuarios registrados en el sitio web mediante una base de datos. Además, implementé reCAPTCHA v2 como método de seguridad para asegurar que el proceso de registro fuera realizado por usuarios reales y no por bots. Este proyecto me permitió comprender mejor la autenticación de usuarios, la validación de formularios y la integración de herramientas de seguridad.
