Proyecto Rescue

¿Qué es Rescue?

Este videojuego realizado en agosto de 2024, fue un videojuego de plataforma disponible para computadoras el cual contaba con una historia, se usó la metologia de SCRUM para crearlo y fue 100% individual.

Objetivo del proyecto

El objetivo principal de este proyecto fue aprender acerca de como funciona el desarrollo de videojuegos.

Herramientas utilizadas:

Godot Motor de videojuegos
GDScript Lógica de la página

Debido a que este proyecto tiene mas de 1 año de antiguedad, no se cuenta con acceso a el y por lo tanto no hay capturas de pantalla del mismo.
