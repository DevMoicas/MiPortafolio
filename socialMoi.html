Proyecto SocialMoi

¿Qué es SocialMoi?

SocialMoi es un proyecto creado en marzo de 2025, similar a lo que se conoce como **Linktree**. Básicamente, muestra botones que te redirigen a mis redes sociales donde me encuentro disponible.

Objetivo del proyecto

El objetivo principal fue profundizar mis conocimientos en desarrollo web y, sobre todo, poner a prueba mi conocimiento en el uso de **APIs**. Este proyecto utiliza la API de Meta para mostrar la foto que tengo en Instagram, lo que significa que la imagen se actualizará automáticamente si cambio mi foto de perfil.

Herramientas utilizadas:

HTML Esqueleto de la página
JavaScript Lógica de la página
API de Instagram Para la foto de perfil
Bootstrap 5 Framework de diseño
Visual Studio Code IDE utilizado
