Proyecto SocialMoi

¿Qué es SocialMoi?

SocialMoi es un proyecto el cual fue creado en marzo de 2025. Dicho proyecto es algo parecido a lo que se conoce como Linktree y, básicamente, lo que hace es mostrar botones los cuales te van a redirigir a todas mis redes sociales donde me encuentro disponible.

Objetivo de crear SocialMoi

El objetivo de crear SocialMoi fue profundizar mis conocimientos en desarrollo web y, sobre todo, poner a prueba mi conocimiento en el uso de APIs. Esto derivó en que, para este proyecto, se utilizó la API de Meta para poder mostrar la foto que tiene el software. Básicamente, la foto se actualizará según la foto de perfil que yo tenga en Instagram; es decir, si cambio mi foto de perfil en Instagram, automáticamente se cambiará en la página.

Heramientas utilizadas:

# Herramienta y/o lenguaje ¿Para que se usó?
1 HTML Para crear el esqueleto de la pagina web
2 JavaScript Para la logica de la pagina web
3 API de Instagram Para obtener la foto de perfil de mi usuario de instagram.
4 Bootstrap 5 Framework usado para el diseño de la pagina
5 Visual Studio Code Se usó como IDE
