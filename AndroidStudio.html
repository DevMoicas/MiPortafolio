Proyecto Login con android studio.

¿Qué es este proyecto?

Este proyecto el cual se desarrolló usando Android Studio + React Native, es un login sencillo el cual ayudó a conocer los fundamentos en la programación para celulares.

Objetivo del proyecto

El objetivo principal fue conocer el desarrollo para celulares, conocer acerca de pruebas unitarias y uso de Android Studio.

Herramientas utilizadas:

Android Studio Entorno de desarrollo
React Native Toda la programación.
